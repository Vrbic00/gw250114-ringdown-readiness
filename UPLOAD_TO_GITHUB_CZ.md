# Jak tuto složku nahrát na GitHub

Složka je připravena jako samostatný veřejný repozitář. Neobsahuje rukopis ani
obrázky článku.

## Varianta A: nový repozitář přes web

1. Přihlaste se na `https://github.com`.
2. Vpravo nahoře stiskněte `+` a zvolte `New repository`.
3. Repository name: `gw250114-hairy-qnm-code`.
4. Visibility: `Public`.
5. Nezaškrtávejte vytvoření README, `.gitignore` ani licence; tyto soubory už
   ve složce jsou.
6. Stiskněte `Create repository`.

GitHub zobrazí příkazy pro existující lokální složku. Pokud nechcete používat
příkazový řádek, použijte GitHub Desktop: `File` > `Add local repository`,
vyberte tuto složku a následně `Publish repository`.

## Varianta B: nahradit obsah staršího repozitáře

Tuto možnost zatím nepoužívejte bez samostatné kontroly. Starší repozitář
`gw250114-ringdown-readiness` popisuje jinou, dřívější fázi projektu a jeho
historie obsahuje rukopis i obrázky. Pro tento článek je přehlednější nový
repozitář.

## Poslední kontrola před zveřejněním

- Otevřete `README.md` a zkontrolujte název článku.
- Doplňte finální DOI článku do `CITATION.cff`, až bude známé.
- Zkontrolujte, že souhlasíte s licencí MIT.
- Nahrajte celý obsah této složky, nikoli nadřazený pracovní projekt.
