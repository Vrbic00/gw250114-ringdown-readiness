# Submission And Framing Memo

## Recommended Framing

The strongest version of the paper is:

```text
A reproducible public-data GW250114 ringdown projection plus a
ringdown-readiness audit for phenomenological metrics.
```

The paper should not be framed as:

```text
GW250114 rules out popular regular black holes.
```

or:

```text
A full beyond-Kerr reanalysis of GW250114.
```

## Target Strategy

Primary ambitious target:

```text
Physical Review D
```

Use this target only if the final manuscript emphasizes the reproducible
method, machine-readable tables, public-data transparency, and clear
ringdown-readiness standard. The novelty must be the framework and standard,
not merely the null result.

Strong thematic fallback:

```text
Classical and Quantum Gravity
```

This is likely the most natural topical fit for ringdown methodology,
perturbation-theory hygiene, and QNM-readiness language.

Possible but less ideal:

```text
JCAP
```

This would require stronger emphasis on gravitational-wave phenomenology and
future observational use. The current manuscript is more GR/QNM-methods
focused than cosmology/astroparticle focused.

## Referee-Sensitive Points

- Make the public-data projection valuable through reproducibility and
  transparency, not through exaggerated constraint strength.
- Keep the static branch unified with the main text through the concept of
  ringdown readiness.
- Do not let the static branch read as a detached catalog of metrics.
- Put detailed robustness and threshold rows in the supplement.
- Use the readiness ladder figure early enough that the static branch feels
  motivated before the reader reaches the results.

## Suggested Main-Text Minimal Set

- Figure 1: public GW250114 projected displacement from zero.
- Figure 2: ringdown-readiness ladder.
- Main Table 1: public projection summary.
- Main Table 2: static readiness summary.

Everything else can be supplementary unless page limits allow a short third
figure for validation errors.

## Current Verdict

The manuscript now exists as a first integrated draft and an Overleaf-ready
review package. The remaining risk is not a missing headline calculation; it is
framing and depth of presentation. If the paper is sold as a public
reproducibility and readiness-standard paper, it is defensible. If it is sold
as an observational exclusion of alternative metrics, it is vulnerable.

Before journal submission, the strongest upgrade would be to add a public
repository/archive link, expand the projection tables, and let an external QNM
expert test whether the readiness framework is useful rather than merely
careful.
